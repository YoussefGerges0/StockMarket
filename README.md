For working email notifications first create an account at https://app.brevo.com/ 
Then go to settings -> SMTP & API -> API Keys& MCP -> Generate API key -> put the api key that u have generated in .env along with the email that u used to login to send from, with its name 

import all required files from docs into postman and MongoDB compass

install the node modules by using this command: npm install
run the server by using this command in the terminal : npm run start:dev
